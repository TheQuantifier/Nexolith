## AI-use category

Select one category. The summaries below do not replace the complete definitions and examples in the policy.

### 1. AI-assisted coding

AI-generated implementation material may be incorporated into my contributions. This includes code, tests, patches, diffs, replacement expressions, pseudocode, configuration, scripts, or implementation instructions that I copy, retype, translate, paraphrase, adapt, or directly implement.

### 2. AI code review or diagnosis only

AI may inspect or discuss code to identify and explain possible problems, but I independently investigate, design, and write all submitted implementation material. I do not use or adapt AI-generated patches, replacement code, tests, pseudocode, exact expressions, or step-by-step implementations.

### 3. AI-assisted documentation only

AI may assist with prose and other non-code material, but it does not create, inspect, review, diagnose, debug, modify, or influence submitted code or tests.

### 4. No AI use

I do not use generative or conversational AI for any Nexolith contribution work, including code, review, debugging, testing, documentation, planning, research, descriptions, or community contributions.
