# Architecture decision records

Architecture decision records (ADRs) capture project choices that affect multiple components or constrain future work. Accepted decisions remain visible even when later superseded.

## Status values

- **Proposed** — open for review.
- **Accepted** — current project direction.
- **Superseded** — replaced by a later ADR.
- **Rejected** — considered but not adopted.

## Template

New ADRs should include:

1. title and status;
2. context and constraints;
3. the decision;
4. consequences and risks;
5. alternatives considered; and
6. links to superseding or related decisions.
